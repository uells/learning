# Прототип игры Dead Spiral
## Сцены
- Солнечная система и позиция человечества (экспозиция). Плавно переключающиеся кадры с функцией перемотки:
  - Солнечная система
  - Расширение солнца
  - Процесс переселения Земли на спутники Сатурна, Юпитера
  - Колонии человечества
- Сцена диалога с персонажем:
  - Место под персонажа
  - Слой ответа персонажа
  - Слой вариантов ответа игрока
- Сцена навигации
  - Карта 
  - Кнопки навигации в виде списка (под картой) + кнопка подтверждения выбора
  - При нажатии кнопки подтвердить - корабль перемещается, а топливо уменьшается
  - Показатели корабля
- Сцена торговли
  - Задник торговли
  - Инвентарь игрока
  - Инвентарь продавца
  - Тригер наведения на предмет -> описание предмета
  - Тригер нажатия -> подтверждение покупки/продажи
  - Предметы
  - Показатели ?
- Сцена случайного события
  - Задник случайного события
  - Объекты случайного события
  - Слой выбора действия
  - Описание события
